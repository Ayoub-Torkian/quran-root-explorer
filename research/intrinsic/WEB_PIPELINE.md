## DATA DEFINITION (what the web IS — never leave ambiguous)
Raw data = Book6: every WORD in every ĀYAH has a grammatical ROOT (ریشه نحوی). The ĀYAH is the container.
Three webs from the SAME data:
- **Concept web** — nodes = ROOTS (~1701 concepts; node ultimately = concept-SENSE, polysemy-split + co-ref-merged);
  EDGE = two roots share an ĀYAH; weight = # āyāt shared (e.g. سمو–ءرض share 224 āyāt; 2:25 has 18 roots → 153 links).
- **Verse web** — nodes = ĀYĀT; edge = two āyāt share rare/distinctive roots (echo, e.g. 12:18↔21:112).
- **Sūra web** — nodes = SŪRAS; edge = two sūras share concepts.
So āyāt/sūras ARE the data: roots-within-āyāt build the concept web; āyāt & sūras are the nodes of the other two.
WEB IS UNIVERSAL: food web is ONE instance (also gene/protein, neural, social, transport, supply-chain, molecules);
food web used as the BENCHMARK (most characterized). Qur'an tested as a web vs the universal framework.

## 0. The NECESSARY ↔ NECESSITY dual (recording rule — apply to EVERY feature)
- **NECESSARY** (establishable, MEASURED): the property is *significantly present vs the right null* on a stated
  substrate + arrangement = a **necessary condition** of the structure. This is what we CAN prove; bank it (graded).
- **NECESSITY** (the strong claim: the configuration is UNIQUELY forced / sufficient): **NOT provable now —
  INSTRUMENT LIMIT** (BASE-TRUTH: absence of proof ≠ absence). Held as the open frontier; never asserted; nulls
  toward it are provisional; revise-up as instruments improve.
- Record each feature as: `NECESSARY: <z, substrate, arrangement, null>` + `NECESSITY: provisional — <flip condition>`.

## 2. THE PIPELINE (6 stages, loop back from 6→1)
1. **IDENTIFY** — pick a food-web property as the candidate feature.
2. **EXTRACT** — define the Qur'ān-web for it: SUBSTRATE (concept-SENSES · roots · verses · sūras · morphology) ×
   EDGE (within-verse co-occurrence · sequential verse→verse · PPMI attraction · rare-shared **echo** ·
   explanation/disambiguation · semantic similarity) × WEIGHT; choose the metric (NODF, Louvain Q, σ, motif-z,
   betweenness, trophic q, cascade curve).
3. **TEST (null)** — curveball (preserve margins) for undirected; degree-preserving swap (Maslov–Sneppen) for
   directed; segment/order-preserving for sequence. Report z + effect size.
4. **VERIFY** — (a) **de-risk**: remove top contributors, re-test (broad vs formula-localized — the test FFL
   survived & triads failed); (b) **multimodal convergence** (≥3 channels = §3); (c) **dynamic stability**:
   re-test under sense-resolution / revelation-order / reading-order (nulls provisional, web = food web in season).
5. **COMPARE** — Qur'ān metric vs the food-web/universal analog (nested? small-world? motif-rich?) AND vs RANDOM
   and control texts.
6. **ANALOGIZE** — name the universal analog; its untested properties become new §1 candidates → loop.
