# Pre-registration — REBUILD THE NODE: the sense-resolved, referent-merged CONCEPT web

*Locked format per `DISCOVERY_CRITERIA.md` (candidate · scale · null · thresholds declared BEFORE running).
A. Torkian, 2026-06-30. Substrate = content roots + intrinsically-derived SENSES; arrangement = DIVINE-DEFAULT.*

## Claim under test
The true node of the Qur'ān's semantic web is **not the root** but the **CONCEPT = (polysemy-split into senses)
AND (co-reference-merged across co-referent roots)**. Re-deriving web structure on concept-nodes vs root-nodes
**materially reorganizes** the web (communities, bridges, paths, field) — i.e. the node choice is a *web-altering
edit*, not a relabel. If true, every downstream web result inherits a sharper unit.

## Why this meets the novelty bar (tested basis, not promise)
Sense-resolution is already **MEASURED** to reveal far more than the blurred root: the heart (قلب·صدر·فؤاد →
~27 graded states, not 3); وقي ≫ 2 senses; قلب ≥ 3. Sense count is a demonstrated **lower bound**, and a sense
re-assignment is a proven high-leverage operation (cf. two-wounds move-cost t=22). This probe applies that proven
instrument to the WHOLE web for the first time.

## Scale / substrate
- **Node:** root-SENSE (content). Polysemy split = **fully intrinsic** (cluster each root's occurrences by
  neighbour context — القرآن يفسر بعضه بعضا as method). Co-reference merge = **the one semi-external step**
  (referent table OR substitutability test: high context-sim + LOW direct co-occurrence). **Test split-only and
  split+merge SEPARATELY**; the merge-dependent result is DEMOTED (flagged provenance), the split is divine-intrinsic.
- **Edges:** above-chance co-occurrence (PPMI) between concept-nodes, verse window.
- **Arrangement:** DIVINE-DEFAULT (sūra→āyah).

## Instrument
1. Per root: gather all occurrences → context vector (co-occurring roots in āyah/window) → **frequency-balanced +
   morphology-aware** clustering → sense-nodes; k chosen by stability, treated as a **lower bound** (re-test at k+).
2. Co-reference: declared referent sets (رسول·نبي·محمد·أحمد→Prophet, etc.) OR substitutability rule; merge.
3. Build concept-web; recompute communities (**STABLE spectral**, not run-to-run-unstable Louvain), betweenness
   bridges, path structure, and the signed interaction-field energy.

## Novelty-deciding statistics
- **Community ARI(concept-web vs root-web)** projected to roots — LOW = reorganization (novel); ~1 = relabel.
- **Bridge-set change** — do top-betweenness nodes change? Count **newly-revealed bridges** (a polysemous root
  split into senses landing in *different* communities = a bridge invisible at root level) — must be *interpretable*.
- **Modularity / field-energy** change under the sharper node.

## Nulls
- (a) **Text's own shuffle** (verse/word shuffle, frequency-preserving) — concept-web structure must exceed it.
- (b) **KEY — random-relabel null:** randomly split roots into pseudo-senses (matched k-distribution) + random
  merges; meaning-based sense/merge must beat this on ARI-divergence + modularity (controls "any repartition moves ARI").
- (c) **G4 frequency confound:** rare senses look distinctive trivially → frequency-match.

## Positive control (MANDATORY, run FIRST)
Plant a known polysemy: take a root, synthetically split its occurrences into two contexts seeded from two
*different* known communities; confirm the sense-clustering recovers the split AND the web places the two senses
in the two communities. **If it cannot recover a planted sense-split, the instrument is blind → reject before
pointing at the Qur'ān.** Negative control: random split → no community separation.

## Thresholds (to enter the graded ledger / discovery bar)
- **G0** divine substrate (split intrinsic; merge-dependent results demoted + reported separately).
- **G2** concept-web structure p<0.05 vs BOTH null (a) and null (b).
- **G5 (effect, binding gate)** ARI(concept vs root) materially < ~0.6 **AND** meaning-based divergence beats the
  random-relabel null by a clear margin **AND** ≥ a handful of *interpretable* newly-revealed bridges.
- **G6** holds across split-half, two sense-resolution levels (k, k+), stable spectral instrument.
- **G7** divergence not reducible to (i) merely adding nodes (random-split null) or (ii) frequency.
- **G9(b)** comparator: does the Qur'ān gain MORE structure from sense-resolution than a matched non-Qur'ān
  Arabic corpus? (the "is it special" test).
