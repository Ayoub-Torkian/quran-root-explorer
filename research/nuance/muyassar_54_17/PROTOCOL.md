# Probe: ميسر للذکر (54:17) — "made easy to remember" (PRE-REGISTERED, frozen)
Frozen 2026-06-08, BEFORE running. Revealed-layer, count-only, no phonology, no comparator.

## Claim (operationalized — ONE facet)
"Easy to remember" is supported, in part, by METRICAL REGULARITY: verses within a sura are
more uniform in length than a random regrouping of the same verses would be. (Uniform
rhythm aids memorisation.) Phonological rhyme/fasila = separate future probe.

## Data / statistic
Verse length = # root-tokens per verse (Book6). For each sura with >=4 verses, CV = sd/mean
of its verse lengths. Statistic M = verse-count-weighted mean within-sura CV (lower = more
regular). Secondary: same with length = # surface words.

## Null (B=300)
Randomly reassign the 6236 verse-lengths to suras, preserving each sura's verse-count;
recompute M. Destroys canonical grouping, keeps the global length distribution + sura sizes.

## Inference + decision (frozen)
z = (M_obs - mean(M_null))/sd(M_null);  one-sided p = (#null <= M_obs + 1)/(B+1).
A. SUPPORTED: M_obs < null with p < 0.005 (B=300) -> within-sura metrical regularity beyond
   chance; report effect (M_obs vs null, % reduction).
B. else -> honest null.
SCOPE: ONE memorability facet (rhythm), descriptive/internal; NOT a comparator claim, NOT
the whole of "easy to remember." Confound noted: within-sura regularity partly reflects
revelation-period coherence (Meccan-short/Medinan-long) — which IS canonical structure, the
thing being measured; reported transparently.
