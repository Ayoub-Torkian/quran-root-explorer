## 3. NEW optional module to teach — "Close-up: how a claim is reviewed"

This is the main addition and the most teachable. Every close-up follows **one locked
8-section investigative standard**, so once a student reads one, they can read them all:

> Problem → Hypothesis → Method & instruments → Results → Gating chain → Interpretation
> → Caveats → Verdict, then Reflection · Summary · Lessons learned · Takeaway · and full
> **Persian + Arabic abstracts**. Each page opens with an **"On this page"** strip.

Teach it as a unit on **methodology, not theology**. The discipline is the lesson: a claim
earns belief by surviving a fixed rule, a proper null, robustness, and replication — not by
being striking or popular.

**Three "claims reviewed" pages, each fully data-driven (every number measured on the text):**

| Page | Verdict | The teachable point |
|---|---|---|
| **🔢 Code 19** (Rashad Khalifa) | REFUTED-ARTIFACT (g 22) | The *orthographic split*: the code reproduces exactly for stable letters (ق, ص) and fails for spelling-variable ones (ن, ي, alif). Across 1,084 counts 19 is the rarest, below chance. A multiple-comparisons artifact — with the genuine anchors (basmala = 19 letters, 114 sūras) fairly credited. |
| **🧮 Word-count miracle** (al-iʿjāz al-ʿadadī, Nawfal) | REFUTED-ARTIFACT (g 35) | Code 19's twin, for words. A few pairs really are equal (dunyā = ākhira = 114; Ādam = ʿĪsā = 25, with Q 3:59's own parallel) — credited. But most fail (life ≠ death, angels ≠ devils), the matches collapse to 0 under a spelling change, and equal counts are ~3–24% by chance. |
| **🕰️ Revelation order** (chronology) | CANDIDATE (g 70) | The fair, credit-forward case. Verse length is a real clock (Meccan 14 → Medinan 30 words/āyah, r = 0.66); tradition, Nöldeke, Bazargan and Sadeghi **converge**. Only passage-level dating over-reaches (method-dependent 2–74%). Includes an elaborate per-school survey (timeline + 6 profiles, cross-referenced). |

**New pedagogical feature — the "Path forward" section.** Each claims-reviewed page now ends
with a **probability-ranked, evidence-grounded roadmap**: for the chronology, how to recover
the true order; for Code 19 and the word-count miracle, the single pre-registered test that
would conclusively settle the claim. Every move is tagged with the MEASURED result it is built
on; the priorities are explicit estimates. Excellent material for a "how would you test this?"
seminar exercise.
